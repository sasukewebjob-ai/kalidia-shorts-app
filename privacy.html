プライバシーポリシー

KALIDIA Shorts（KALIDIAバドミントンチャンネル　ショート動画の予約投稿ツール）

1. このツールの利用者

本ツールは、KALIDIAバドミントンチャンネルの運営者が自分のチャンネルを管理するためだけに使う個人用ツールです。一般の方の情報を集めることはありません。

2. 取得する情報

運営者が Google アカウントで許可した範囲で、YouTube Data API を通じて次の情報を扱います。

  • Google の認証情報（アクセストークン・更新トークン）
  • 運営者のチャンネルの動画一覧（動画ID・タイトル・公開日・再生回数・長さ）
  • 運営者のチャンネルの再生リストの情報

3. 利用目的

  • ショート動画のアップロードと、公開日時の予約
  • 再生リスト「ショートで紹介した本編」への動画の追加
  • ショートにする動画を選ぶための、動画一覧の作成

上記以外の目的（広告・分析・販売など）には使用しません。

4. 保存場所と第三者への提供

取得した情報は、運営者自身のパソコンの中にだけ保存します。Google の API との通信を除き、外部のサーバーに送信・保存することはなく、第三者に提供・共有することもありません。

5. Google API サービスのユーザーデータに関するポリシー

本ツールによる Google API から受け取った情報の使用および他のアプリへの転送は、限定的使用の要件を含む Google API サービスのユーザーデータに関するポリシー に準拠します。

6. アクセスの取り消しと情報の削除

本ツールへのアクセス許可は、Google アカウントの「サードパーティ製のアプリとサービス」からいつでも取り消せます。パソコンに保存した認証情報は、本ツールのフォルダから削除することで消去されます。

7. 改定

内容を変更する場合は、このページを更新してお知らせします。

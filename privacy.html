プライバシーポリシー

KALIDIA Shorts（KALIDIAバドミントンチャンネル　ショート動画の予約投稿ツール）

1. このツールの利用者

本ツールは、KALIDIAバドミントンチャンネルの運営者が自分のチャンネルを管理するためだけに使う個人用ツールです。一般の方の情報を集めることはありません。

2. 取得する情報

運営者が Google アカウントで許可した範囲で、YouTube Data API・YouTube Analytics API・Google Drive API を通じて次の情報を扱います。

  • Google の認証情報（アクセストークン・更新トークン）
  • 運営者のチャンネルの動画一覧（動画ID・タイトル・公開日・再生回数・長さ）
  • 運営者のチャンネルの再生リストの情報
  • 運営者のチャンネルの動画の数字（再生回数・高評価・コメント数・平均視聴率・平均視聴時間）
  • 本ツールが Google ドライブに作成したファイルの情報（ファイルID・ファイル名）。本ツールが作成していないファイルにはアクセスしません

運営者が TikTok アカウントで許可した範囲で、TikTok の Login Kit と Content Posting API を通じて次の情報を扱います。

  • TikTok の認証情報（アクセストークン・更新トークン）
  • 運営者の TikTok アカウントの基本情報（表示名・アイコン・ユーザーID・フォロワー数）
  • 運営者が投稿した動画の情報（投稿ID・処理の状態・再生回数・いいね・コメント・シェアの数）

3. 利用目的

  • ショート動画のアップロードと、公開日時の予約
  • 再生リスト「ショートで紹介した本編」への動画の追加
  • ショートにする動画を選ぶための、動画一覧の作成
  • 投稿したショートの数字を、運営者がふり返るための記録
  • Threads に動画を投稿するための、Google ドライブへの一時的な動画の配置（読み込みが終わったらすぐ削除します）
  • 運営者の TikTok アカウントへの動画の送信（下書きへの送信）

上記以外の目的（広告・販売など）には使用しません。

4. 保存場所と第三者への提供

取得した情報は、運営者自身のパソコンと、運営者自身の Google スプレッドシート（投稿したショートの数字の記録）にだけ保存します。Google と TikTok の API との通信を除き、外部のサーバーに送信・保存することはなく、第三者に提供・共有することもありません。

5. Google API サービスのユーザーデータに関するポリシー

本ツールによる Google API から受け取った情報の使用および他のアプリへの転送は、限定的使用の要件を含む Google API サービスのユーザーデータに関するポリシー に準拠します。

6. アクセスの取り消しと情報の削除

本ツールへのアクセス許可は、Google アカウントの「サードパーティ製のアプリとサービス」から、TikTok は アプリの「設定とプライバシー」→「セキュリティ」→「アプリの権限」から、いつでも取り消せます。パソコンに保存した認証情報は、本ツールのフォルダから削除することで消去されます。

7. 改定

内容を変更する場合は、このページを更新してお知らせします。
